# workspace-audit QA eval, 2026-11-16

## Method

Programmatic fact checks: expectations in `scenarios/*/expected.json` are locked before the run; the runner builds each fixture, runs the deterministic scanner and compares the actual JSON to the expectations. The LLM layer of the skill is not covered by this evaluation. Asymmetry: FAIL proves a defect, PASS only means "not refuted in this run".

## Run history

- 2026-10-30, first run of the original suite: 58/62. The eval did its job and found real scanner defects: (1) git grep flagged env assignments (`API_KEY = os.environ[...]`) as secrets — fixed, the pattern now requires a quoted literal of 8+ chars; (2) the file scan missed `DB_PASSWORD="..."` — word boundary `\b` does not fire before an underscore in compound names, replaced with a non-alphanumeric lookbehind. Both fixes confirmed by a rerun: 62/62.
- 2026-11-02, v0.2 additions (baseline diff, import-aware twin drift, memory line limit, chain budget): 71/71.
- 2026-11-16, English localization for the public release, bilingual junk heuristics added, rules 0.2.1: 71/71. One integration seam fixed during the release: the runner still compared skill sync against the old Russian value.
